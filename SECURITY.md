# Security Policy

This is a private repository that handles personal health data.

## Reporting a vulnerability

Do not open a public issue. Report privately to the owner, [@sudoCreate258](https://github.com/sudoCreate258), using GitHub private vulnerability reporting or a direct message.

Include a description, steps to reproduce, and the affected files or commands. Do not include real health data or secrets.

## Handling

Reports are acknowledged as soon as practical, fixed on a private branch, and merged through `develop`.

## Secrets

Never commit `.env` or real data. Use `.env.example` for placeholders.
